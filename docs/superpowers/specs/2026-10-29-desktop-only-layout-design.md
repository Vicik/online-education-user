# 桌面端固定宽度布局设计

## 目标

将公开网站调整为仅面向电脑网页端：页面主体、页头内容区和页脚内容区固定为 `1200px`，在浏览器中水平居中；浏览器窗口不足时保持桌面排版并允许横向滚动。

## 范围

- 始终显示六项桌面主导航，删除移动端菜单。
- 首页 Banner 与各列表分区固定为 `1200px` 宽。
- 拼团、最新课程和推荐课程始终保持四列。
- 删除只服务于手机端的媒体查询，保留键盘焦点、跳到正文和减少动态效果支持。

## 非目标

- 不调整现有颜色、字体、文案、接口、SSR、SEO 或缓存行为。
- 不实现其他路由或后端能力。
- 不提交、推送或部署代码。

## 已选方案

采用固定桌面画布，而不是让桌面组件随窄窗口压缩。全局最小宽度与内容宽度均以现有 `--page-width: 75rem`（`1200px`）为唯一来源，避免多个不一致的宽度常量。
